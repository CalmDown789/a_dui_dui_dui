# 成员 C 交付契约

## 固定网络

- 输入：640×360，单通道 Y，INT8。
- L1：3×3，1→8，PReLU。
- L2：3×3，8→16，PReLU。
- L3：3×3，16→4。
- 输出：2 倍子像素重排后得到 1280×720 单通道 Y，INT8。
- 累加：INT32。

## 固定职责

- C1：AXI4-Stream 与 AXI4-Lite 接口、寄存器映射。
- C2：HLS 行缓存、滑窗、并行乘加、PReLU、子像素重排。
- C3：Python 定点参考实现。
- C4：C 仿真与位精确比对。
- C5：综合脚本、约束与综合报告。
- C6：PYNQ Python 驱动。
- C7：联调记录。
- C8：汇报稿与演示材料。

## 外部依赖

- 成员 A：base overlay、Block Design、地址分配、位流和板上运行。
- 成员 B：训练权重、INT8 量化规则、逐层黄金结果和测试向量。

在成员 B 数据到达前，成员 C 使用固定小尺寸输入和固定权重完成逻辑自测，不等待空转。

## 决策边界

- 成员 C 不替成员 A 决定 overlay、DMA/VDMA、时钟和地址规划。
- 成员 C 不替成员 B 决定模型 padding、量化尺度、零点、舍入、饱和和权重排列。
- 跨角色决定先写入 `TEAM_CONFIRMATION.md` 征求对应成员意见，再形成冻结规格。
- 成员 C 可以直接决定自己代码内部且不影响外部接口的实现细节。
