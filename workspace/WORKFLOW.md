# 工作约定

## 一次任务一个候选

当前冻结交付只读。新任务在 `candidates/<日期>_<任务>/` 创建候选，先写 `README.md`：基线 SHA、目标、入口、验收条件。输出放该候选的 `results/`，缓存放 `build/`，禁止向工作区根目录写一次性 `_*.txt` 或仿真产物。旧目录保留路径兼容，后续任务采用此结构。

## 记录只留可接手的内容

`docs/CURRENT_STATUS.md` 仅维护当前基线、已证实结果、未完成项和下一步；`docs/HISTORY.md` 仅维护重要决策与口径变更。一次任务结束写一份简短结果：变更、测量、证据路径、限制、下一步。逐条命令输出放本次 `results/`，不要追加到长期记忆。统计应保留失败、恢复与尾帧。

历史原件压缩备份到工作区外 `C:/Users/Administrator/srtp_backup/2026-10-09-workspace-cleanup/`；清理清单记录实际删掉的路径与原因。冻结交付中的状态原文即使过时，也由外部最终收据补充，避免破坏身份哈希。

## 同步范围

GitHub 保存源代码、约束、模型 MEM、必要复现数据、复现脚本、简洁报告、身份及校验清单。可运行的当前 V2 工作包单独同步；其源文件保持字节一致。

完整原始报文、512 帧输出、旧候选、安装包、虚拟环境和仿真缓存留本地。大证据包以 SHA256、字节数、文件清单与本地路径引用。发布后核对远端提交和本地提交一致。同步到独立维护分支，基线项目分支不随目录整理自动升级。

## 验收与工具

先做交付 SHA 校验与只读文件预检；整理任务无需重复上板。RTL 改动才重新执行相应回归、综合、布局布线及 BIT 身份绑定。运行入口与硬件身份守卫保持完整。

PowerShell 原生路径操作，删除前检查解析后的绝对路径属于指定工作区；Git 工作树、未提交源码和原始失败证据不能按目录名批量删除。RTL/Tcl 用 UTF-8 无 BOM；XSim `-O0` 历史问题与版本限制应按具体源树/工具记录引用。
