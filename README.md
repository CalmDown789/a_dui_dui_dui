# 轻量视频超分 FPGA 10 小时冲刺

本仓库用于三人团队的 PLD 项目冲刺。当前优先级只有一个：在 10 小时内形成可复现、可演示、可提交的成果。

目标平台已经确定为 **PYNQ-Z2（XC7Z020-1CLG400C）**，优先复用现有的 Vivado/XSim RTL 与验证资产，不在本轮切换到 ACX750-200T 路线。

本人的团队身份按 **成员 C** 执行，负责提供 FPGA 侧 RTL、testbench、综合实现和验证证据，主要包括：

- 运行并维护核心模块 testbench；
- 检查 signed 位宽、valid 延迟和分组累加结果；
- 整理综合资源、时序报告、波形和 PASS 日志；
- 编写复现步骤、接口说明和最终演示检查表。

当前仓库已经导入此前在 PYNQ-Z2 目标器件上验证过的窗口生成器、DSP 定向 9 路点积、12 通道累加器及对应 testbench。软件算法继续以已经跑通的 FSRCNN 工程为参考，不重新寻找另一套网络作为本轮起点。

详细安排见 [SPRINT_PLAN.md](SPRINT_PLAN.md)。

## 目录约定

- `rtl/`：可综合 RTL 源码
- `tb/`：testbench 与测试向量
- `scripts/`：仿真、综合和报告脚本
- `docs/`：接口说明、架构图和演示材料
- `results/`：经过筛选的日志、报告与截图

Vivado 自动生成目录、缓存和临时日志不提交到 Git。
