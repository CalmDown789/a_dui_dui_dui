# 成员 A：模型候选软件验收阶段报告

日期：2026-10-06
阶段：R0F / R0T / R0-QAT 同条件 4K 质量与整数包复核
范围：PC 软件与 A 侧整数参考；未修改正式冻结资产、B/C 工程或 GitHub 远端。

## 当前结论

在 25 张留出源帧、两种合成降采样口径（共 50 组配对条件）上，R0-QAT seed123、seed456 的整数参考均超过双三次基线，且相对 R0T 浮点基线的平均 PSNR 差在计划书的 0.30 dB 范围内。两个 QAT 候选的整数结果也都高于各自 checkpoint 的普通浮点前向；这是本次测试集上的实测结果，不应外推成普遍规律。

同一校准集下，R0F 和 R0T 的直接 PTQ 分别损失约 0.29 dB、0.65 dB，未达到计划书建议的 0.10 dB 量化筛选线。QAT 把这项损失恢复了，但这只证明 A 侧 CPU 整数参考的结果，不是 B RTL 或 FPGA 验收。

正式 R0 权重、量化包和 Golden 仍保持不变。R0-QAT 只能作为待 B 侧独立对拍的实验候选，不能直接替换正式包。

## 数据与评测口径

- 链路：`960×540 Y8 → FSRCNN×2 → 1920×1080 Y8 → Keys bicubic×2 → 3840×2160 Y8`，Keys 参数 `a=-0.5`。
- 留出场景：UVG Bosphorus 10 帧、ReadySetGo 10 帧、ShakeNDry 5 帧；三条序列未参与候选训练。
- 每个源帧分别按 FFmpeg bicubic 和 Pillow bicubic 生成 960×540 输入。故 50 组条件对应 25 个唯一源帧，不按 50 张独立图像统计。
- 校准使用训练侧 YachtRide 的 60 组 FFmpeg 配对输入；最终测试集未用于校准。
- 只评价 Y 通道，像素范围 0–255，PSNR 峰值 255；PSNR/SSIM 分别报告全图（border=0）及中心裁边 8 像素（border=8）。SSIM 为 11×11 高斯窗、sigma=1.5。
- UVG 源视频是有损 HEVC 解码或公开 4K YUV 内容；合成降采样指标不等于相机原生 540p/4K ground truth。

## 筛选门槛判断

- `相对双三次平均 PSNR ≥ +0.20 dB，且 SSIM 不低于双三次`：本次四个整数候选均通过。
- `相对 R0T 平均 PSNR 损失 ≤ 0.30 dB`：两种 QAT seed 均通过；seed456 全图约低 0.005 dB，seed123 全图约低 0.068 dB。
- `同候选整数化 PSNR 损失 ≤ 0.10 dB`：R0F、R0T 的直接 PTQ 未通过；两种 QAT seed 的整数输出未出现损失，且本测试上分别高于各自浮点前向约 0.70 dB、0.39 dB。
- 当前建议：若继续送 B 侧做实验对拍，优先用 seed456 候选；seed123 保留作跨种子复核。两者都仍是实验包，不改变正式 R0。

## 既有结构优化结论

此前结构筛选表明：R1（输出头 5×5 改 3×3）约减少 36.2% MAC，相对 R0T 浮点损失约 0.267 dB，处于计划书质量边界附近；R4 减少约 67.2% MAC，但相对 R0T 损失约 0.786 dB，不满足当前质量线。详见 [模型优化阶段报告](MODEL_OPTIMIZATION_REPORT_2026-10-06.md)。这些是 FP32 软件候选结果，不代表新的 RTL 或硬件性能。
