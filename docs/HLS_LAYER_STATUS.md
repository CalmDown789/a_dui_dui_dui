# 可配置 Cin/Cout 卷积层阶段记录

## 当前数据流

输入顺序：`row → column → input_channel`。

输出顺序：`row → column → output_channel`。

每个空间位置执行：

1. 初始化最多 16 个输出通道累加器；
2. 依次接收最多 16 个输入通道；
3. 更新各输入通道的两行缓存和 3×3 窗口；
4. 对每个输出通道执行 9 路空间乘法；
5. 在所有输入通道之间累加；
6. 依次输出各输出通道的 INT32 结果。

该结构只实例化一组空间乘法后端，在输入/输出通道方向进行时间复用。

## C 仿真

测试配置为 4×5×2 输入、3 个输出通道：

- 输出通道 0：正权重、负权重和正偏置；
- 输出通道 1：相反权重和负偏置；
- 输出通道 2：零权重，仅输出偏置。

完整窗口数为 6，每个窗口输出 3 个通道，共 18 个结果，全部逐项通过：

`CONV3X3_LAYER_TEST_PASS results=18`

测试数据不再由 C++ testbench 独立计算。`python/generate_layer_vector.py` 先调用 Python 参考模型生成二进制向量和 `layer_vector.hpp`，HLS testbench 再逐元素比较该头文件中的期望值，已经形成 Python→HLS 的共享向量闭环。

## HLS 综合结果

目标器件：`xc7z020-clg400-1`。自测时钟约束：10 ns。

| 指标 | 结果 |
|---|---:|
| 输出通道计算循环 II | 1 |
| 输出写回循环 II | 1 |
| 估算 Fmax | 140.87 MHz |
| BRAM_18K | 16 / 280 |
| DSP | 6 / 220 |
| FF | 2753 / 106400 |
| LUT | 2039 / 53200 |

## 接口处理

- 3×3 权重核维度完全分区，以支持 9 路并行读取。
- bias 保持单一 `ap_memory` 接口，没有暴露为 16 个独立标量端口。
- 权重和 bias 当前仍是层引擎存储接口；最终采用初始化常量、AXI-Lite 装载还是 PS 侧搬运，需要结合成员 A/B 的交付方式决定。

## 结论边界

- 当前是一个可复用卷积层引擎，不是已经串联的三层网络。
- 输出为 INT32，尚未插入成员 B 的 requantize/PReLU。
- 当前只输出完整窗口，padding 尚未冻结。
- HLS 资源/时序是估算值，不是 Vivado 实现结果或板上性能。
