## 彩色视频的颜色处理

输入视频为 Blender Foundation 的《Big Buck Bunny》(2008)，使用公开的 CC BY 3.0 许可。短片取源视频第 1440～1524 帧，每隔 12 帧取一帧，无音频。素材署名按官方要求标注为 `(c) copyright 2008, Blender Foundation / www.bigbuckbunny.org`；见[授权说明](https://peach.blender.org/about/)和[CC BY 3.0 条款](https://creativecommons.org/licenses/by/3.0/)。

处理流程：从原始 1280×720 YUV420 视频以 FFmpeg/libswscale Lanczos 将 Y、Cb、Cr 按 limited-to-full 范围扩至 1920×1080；展示时丢弃该次缩放得到的 Y，换入既有 960×540 输入对应的 1920×1080 冻结整数 Y Golden，保留放大后的 Cb/Cr 合成彩色画面。原 Theora 颜色矩阵元数据标记为 unknown，演示明确按 BT.709 解释；最终 H.264 为 full-range 标记的 yuv420p、2 fps。此假设影响色彩观感，后续须与板卡视频接口的矩阵/范围约定一致。

这段视频说明 A 侧可以完成 Y 超分并在 PC 上合成彩色输出。它读取预先计算的 Golden，不表示 FPGA 实时处理、传输速率或板上画质。

## 实际整数模型画质结果

指标来自冻结权重和整数参考实现的实际逐层计算。固定为 uint8 Y、归一化 `[0,1]`、PSNR 峰值 1、四周各裁 2 像素；SSIM 使用项目内 11×11 Gaussian、sigma 1.5 的实现。双三次基线是 PyTorch bicubic、`align_corners=False`。20 个样本均比较双三次、FP32 和整数模型。

| 样本组 | 数量 | 双三次 PSNR / SSIM | FP32 PSNR / SSIM | 实际整数 PSNR / SSIM |
| --- | ---: | ---: | ---: | ---: |
| Set5 验证图 | 5 | 32.640 dB / 0.92782 | 34.120 dB / 0.94054 | 34.018 dB / 0.93784 |
| Big Buck Bunny 配对帧 | 8 | 46.604 dB / 0.99389 | 48.345 dB / 0.99455 | 46.366 dB / 0.98862 |
| 合成压力图 | 7 | 35.390 dB / 0.98472 | 36.433 dB / 0.98397 | 36.237 dB / 0.97955 |

Set5 曾用于训练期间选取 checkpoint，因此这五张图不能当成独立测试集。逐图结果在 CSV 中。Set5 平均整数结果高于双三次 1.379 dB，较 FP32 低 0.102 dB，与此前量化报告大体一致。

8 个视频配对样本由授权源片逐帧解码得到 1280×720 RGB，再用 Pillow 转 Y 作为真值；同一 Y 以训练使用的 Pillow BICUBIC 缩至 640×360，交给 ×2 网络还原至 1280×720。它们是动画的配对软件评测，不是部署 960×540→1920×1080 的板卡实测。该组整数均值比双三次低 0.238 dB，显示当前模型并非对所有内容都优于插值；还需扩大独立视频场景才能评估真实内容泛化。

合成组包含小字笔画、建筑立面、人像和 4 帧运动图。它们从程序生成的 1920×1080 灰度真值按 Pillow BICUBIC 生成 960×540 输入，评测可对齐该真值，但只能作为结构压力测试。其整数均值比双三次高 0.848 dB。当前合成组中，小字图最难：整数 PSNR 30.002 dB、SSIM 0.96727，报告附有该例误差较大的局部裁剪。不能把合成指标当成真实街景表现。

Set5 整数/FP32 均值一致性 PSNR 为 50.103 dB；授权视频为 50.233 dB；合成组为 50.600 dB。该指标只说明两个模型输出彼此接近，不代替它们相对真值的 PSNR/SSIM。

## 复现

数据及源视频只放在忽略目录 `.data/`。缺少 Set5 时运行 `python scripts/download_data.py`；缺少 BBB 源片时运行 `python scripts/prepare_public_sequence.py`。脚本会校验冻结的数据/视频 SHA-256。然后从仓库根目录运行：

```powershell
python scripts/evaluate_integer_quality.py
python scripts/create_color_video_demo.py
python scripts/package_color_quality_report.py
```

两条脚本默认拒绝覆盖已存在的非空输出目录；复算指标可指定一个新的 `--output-dir`。整数模型检查同时验证 960×540 权威输入的重新计算结果与冻结 Golden 逐字节相同。模型 checkpoint、quant 参数、Set5 集合摘要和源视频 SHA-256 都记在 JSON 报告内。当前报告运行于 RTX 5060 CUDA 环境，未重训、未改模型或量化资产。

## 验收边界

这次交付包含 PC 彩色演示和软件画质评测；自动读取 Integer Golden 不等于实际整数模型已经上板，也不等于 C 的视频输入/输出路径已经连通。bitstream 实现、接口矩阵范围确认和实体板采集仍需单独完成。素材授权说明来自 Blender Foundation 官方页面；原片本身没有被复制进仓库。
