# 3×3 HLS 算术核心阶段记录

## 当前完成

- 实现 INT8 激活与 INT8 权重的 3×3 多通道乘加。
- 最大输入通道数为 16，累加结果为 INT32。
- 3×3 空间维度完全展开；输入通道顺序累加。
- 提供 INT8 饱和辅助函数和 2× Pixel Shuffle 块索引候选实现。
- C 仿真覆盖单通道、双通道有符号运算、偏置、饱和边界和 2×2 重排。

C 仿真通过标志：`SR_PRIMITIVES_TEST_PASS`。

## HLS 综合结果

目标器件：`xc7z020-clg400-1`。自测时钟约束：10 ns。

| 指标 | 结果 |
|---|---:|
| 通道循环 II | 1 |
| 顶层延迟 | 24 cycles |
| 顶层启动间隔 | 22 cycles |
| 估算 Fmax | 150.22 MHz |
| DSP | 6 / 220 |
| FF | 556 / 106400 |
| LUT | 576 / 53200 |
| BRAM_18K | 0 / 280 |

初版未分区 3×3 数组时，9 个并行读操作受存储端口限制，通道循环只能达到 `II=5`。
对像素与权重的两个卷积核维度执行 complete partition 后，综合达到 `II=1`，循环约束全部满足。

## 结论边界

- 这是一个像素位置、一个输出通道的算术后端，不是完整网络。
- 当前 `ap_memory` 端口用于独立综合验证，最终会嵌入行缓存/窗口和权重存储，不作为成员 A 的 overlay 接口。
- 10 ns 是成员 C 的候选验证条件，不代表成员 A 已确认系统时钟。
- Pixel Shuffle 当前采用标准 `channel = row_offset*2 + col_offset` 候选顺序，仍需与成员 B 模型导出结果比对。
- `saturate_int8()` 只验证饱和单元，不代表最终 requantize 公式已经确定。
