  The local state copy's issue output still had fanout 347. The route from
  that control net alone added 1.566 ns, and the following MUXF7-to-DSP net

  all 76,574 routable nets eventually completed with 0 routing errors.

Decision
  REJECT this RTL candidate and keep the original shared-phase implementation.
  The synthesis WNS improvement did not survive routing: final WNS regressed
  by 0.767 ns, TNS regressed by about 25,835 ns, LUT increased by 8,568
  (26.7%), and route time was about 1.9x baseline. BRAM/DSP counts were
  unchanged. The implementation still misses 200 MHz.

Third-party diagnosis
  Copying phase state once per output lane did not localize the actual
  critical loads: each copy still feeds hundreds of selection cells, and
  the path remains dominated by routing rather than logic depth. This is
  evidence against repeating the same lane-copy strategy or treating the
  synth-only WNS as a signoff result. The next investigation should inspect
  the 8-way phase-dependent activation/weight selection topology and placement
  of its multiplier groups. Any new trial must include post-route WNS/TNS,
  fanout, and route time before it can replace the current RTL.
